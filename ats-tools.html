The workflow

What to do once a company is detected. The goal is to get a working slug into a connector so the Job Finder searches that employer.

  1. Detect — paste a careers / apply URL (one, or many in Batch). Green = a connector can reach it.
  2. Confirm — for a green result, run Test-fetch to prove the board actually returns jobs. Detection alone isn't proof.
  3. Copy the slug — grab the paste-ready slug (or Workday config row) from the result or the batch table.
  4. Add it — paste the slug into that connector's board list (greenhouse.js, lever.js, ashby.js, smartrecruiters.js) or the Workday config.
  5. Ship — commit & push; Netlify auto-deploys. The employer is now live in the Job Finder.

Amber = needs credentials (skip for this keyless setup). Red = blocks server requests (skip). Unknown = try the deep-probe, else it's a custom portal — set aside.
